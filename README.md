#### Description:
Youtube Focus is an application made to help people's attention spans
#### What it helps:
This extension is very dear to me due to me checking the comments when the video is running, and therefore ruining my attention from outer stimuli. This isn't just a problem for me though and many other people around the globe, and that is why I created this application to help others around me for free! 
#### What resources it uses:
This project was made using html, css, javascript, and Manifest V3 for the chrome extension
#### What it does:
What it does: turns the comments on if the video is paused, if not then the comments are off. This only happens if the toggle switch is set to enabled of course
## Small note:
Also slightly meant to be paired with the other extension untrap to make Youtube much more optimal. That is just my personal opinion though. 
#### What files it uses in the project:
'.giattributes' Used as a rulebook for Github.
'README.md' For this project of course.
'content.js' JS made to turn off and on the comments.
'Youtube_Focus.js' JS for the toggle button and overall ui when you click the extension.
'styles.css' The css to improve the Youtube_Focus.html's look on the browser.
'Youtube_Focus.html' html or ui for the popup winder and creates the button that turns it off and on.
